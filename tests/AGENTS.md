# tests 说明

适用范围：`tests/`。同时遵守根 `../AGENTS.md`；表格扩展约定见 `../client/AGENTS.md`。

- 在 v2 的 `external/onebot-poke` 执行测试，不在独立源码目录安装依赖。
- 协议、权限及冷却测试使用真实适配器解析和独立内存数据库，不发送真实 QQ 消息，不修改宿主场景。
- 表格测试在 jsdom 内挂载真实 SchemaForm/ui-kit，覆盖字段编辑、增删后的草稿隔离、无排序按钮、默认空表、恢复默认不生成示例、零权重、未知字段和扩展释放；DOM 测试不代表浏览器视觉验证。
- 测试结束释放 React root、Cordis fiber、监听器、定时器和 DOM。不得用模拟渲染器替代宿主控件来声称集成通过。
- 发布脚本测试在独立临时目录复制真实脚本，通过 PATH 注入 Git/Yarn/npm 命令替身；不得真实提交、发布、打标签或推送。替身的开发检查只生成夹具产物，不运行真实测试，避免发布脚本调用 `check` 导致递归。隔离发布需守住运行副本文件不变、缓存不写回、凭证不复制及 workspace 路径不越界。
- npm 交互认证测试使用真实伪终端和 npm 命令替身，验证 stdin/stdout 的 TTY 状态与 OTP 脱敏；不得打开真实认证网页、读取用户登录令牌或执行真实发布。
- 根说明登记守卫需覆盖每份子目录 AGENTS.md，且根清单里的路径必须存在。
