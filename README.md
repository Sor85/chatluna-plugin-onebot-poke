# ChatLuna OneBot Poke

ChatLuna 插件，响应 **NapCat、SnowLuma、LLBOT（LuckyLilliaBot）** 的 OneBot v11 戳一戳事件，按权重选择一条预设消息或执行一条框架指令，并限制响应频率。无需调用模型。

> **启用前：** 如果同时启用了 ChatLuna 内置的 `@chatluna/chat-onebot`，在适用路由中关闭 **OneBot → 事件 → 戳一戳**（`onebot.events.poke = false`）。内置功能默认唤醒模型，保留开启会产生额外模型回复。本插件不会擅自修改路由或拦截其他插件的事件。

## 功能

- 群聊和私聊分别开关，仅接收戳向当前机器人的 `notice/notify/poke`
- 预设消息和指令共同参与加权抽取，每次只执行一个有效项
- 权重为相对值，无需合计为 100；权重 0、空白内容不参与抽取；全部禁用时不响应
- 默认 1 秒冷却，按“机器人＋会话＋用户”隔离，可改为整个会话或当前机器人共用
- 间隔从动作开始计算，期间事件丢弃，不排队、不延长冷却；执行失败也消耗本次冷却，防止连续重试刷屏
- 即使间隔为 0，同一作用域内仍不并发执行动作；卸载插件清理监听器、计时器及冷却状态
- 冷却只保存在内存，插件重载或进程重启后重置

## 配置

所有配置由插件设置页的原生 SchemaForm 编辑，无独立网页或额外管理服务。加权响应以表格列表展示，支持直接编辑类型、权重和内容，以及新增和删除响应。

```yaml
- name: chatluna-plugin-onebot-poke
  config:
    group: true
    private: true
    cooldownSeconds: 1
    cooldownScope: user
    actions:
      - type: message
        weight: 70
        content: 收到戳一戳。
      - type: message
        weight: 20
        content: '当前用户：{userId}'
      - type: command
        weight: 10
        content: help
```

上述配置仅为手动添加后的示例，概率分别为 70%、20%、10%。默认响应列表为空，不添加示例内容；配置有效响应后才会回复消息或执行指令。

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| `group` | `true` | 群聊响应 |
| `private` | `true` | 私聊响应 |
| `cooldownSeconds` | `1` | 响应间隔，单位秒，范围 0–86400，支持小数 |
| `cooldownScope` | `user` | `user`：会话内每位用户独立；`channel`：会话共用；`bot`：当前机器人全局共用 |
| `actions[].type` | `message` | `message` 回复消息；`command` 执行指令 |
| `actions[].weight` | `1` | 非负相对权重，0 为禁用 |
| `actions[].content` | 空字符串 | 消息正文或不含前缀的指令 |

### 消息和指令

**消息按纯文本发送**，不会解析 CQ 码、Satori 元素或 HTML；例如 `<at id="123"/>` 会原样显示。指令自身返回的图片、语音等内容仍由原指令正常发送。

指令是 ChatLuna 的 Koishi 兼容层指令，不是系统 shell、模型工具名或直接发给模型的提示词。填写 `help`，而不是 `/help`；带参数时填写完整指令，例如 `某个已安装指令 {userId}`。对应命令插件必须已经安装并启用。

指令使用**实际戳人者**的用户身份、群聊/私聊上下文和数据库权限，不提升权限；命令级和选项级权限仍由框架检查。宿主标记为忽略的用户或频道不会响应。因为事件明确指向当前机器人，不按频道的默认 assignee 转交给其他机器人。

当前 ChatLuna 的选项权限会继承父命令权限，单独给选项设置较高 `authority` 不一定构成限制。敏感动作应使用独立的高权限命令，或在宿主权限规则中显式限制 `command:<命令名>:option:<选项名>`；本插件不改写宿主权限策略。

动作不会重新派发为普通消息，不会额外进入模型聊天管线；这不影响其他插件直接监听原始戳一戳事件。无效命令和权限不足按原命令框架的行为处理，不会另抽一个动作作为替代。命令可能自身包含交互、数据库写入或多条回复；这些仍由该命令负责。notice 不走普通消息中间件，因此只在普通消息中间件实现的第三方限制不会自动生效；不宜配置依赖该限制的敏感指令。

正文与指令均支持以下占位符，未知占位符保留原样：

| 占位符 | 内容 |
| --- | --- |
| `{userId}` | 戳人者 QQ 号 |
| `{botId}` | 当前机器人 QQ 号 |
| `{groupId}` | 群号，私聊为空字符串 |

不提供昵称、原始事件文本或脚本表达式插值，避免向指令插入不可信文本。
